# arena-game: agent instructions

Demo game for the fictional Arena API. `openapi/arena.json` is a copy of the spec from `sabuj000/arena-docs`. API changes start there. After that PR is merged, copy the file here and run `npm run gen:sdk`. `npm run check:spec-drift` fails if the copy differs from arena-docs `main`.

- `sdk/types.ts` and `sdk/client.ts` are generated by `npm run gen:sdk`. Never edit them by hand; change `scripts/gen-sdk.mjs`.
- `sandbox/` implements the API in the browser. `tests/contract.test.ts` must pass: it checks the sandbox against the spec.
- Code is plain TypeScript that Node 22 runs by type stripping: `.ts` import extensions, `import type`, no enums or parameter properties.
- Run `npm test` and `npm run typecheck` before opening a PR. Branch `feat/<summary>`. Never merge your own PR.
- Arena is fictional. The sandbox is not a real service; keep that clear in the UI and docs.
